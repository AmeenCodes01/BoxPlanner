# React + TypeScript + Vite

(wanted to practice & fully understand the **useReducer** hook too, used for all the logic)

A simple local-storage todo list I wanted for myself. Especially the green-golden theme.

- Add all your tasks
- Create boxes (categories/sections whatever)
- Add tasks to boxes
- Add/Remove tags to boxes as many as you like.
